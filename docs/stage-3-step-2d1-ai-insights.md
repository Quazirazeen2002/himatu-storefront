## 1. Engine Philosophy & Safety Mandate

The HIMATU AI Business Insights Engine translates raw commerce telemetry into actionable executive observations for the store owner.

### Strict Safety Rules
1. **Zero Hallucination / Strict Numerical Grounding**: The AI model is strictly prohibited from inventing numbers, estimating imaginary trends, or claiming patterns not corroborated by database aggregates.
2. **Read-Only Advisory Role**: The engine has zero mutation authority. It cannot modify product pricing, cancel orders, adjust stock, or alter customer profiles.
3. **Transparent Provenance**: Every insight clearly identifies whether it was generated by an active LLM provider (`source: "ai-generated"`) or by the deterministic rule fallback (`source: "rule-based"`).
4. **Actionable Destinations**: Every insight provides a verified deep-link within the HIMATU control center (e.g. `/admin/inventory`, `/admin/orders?status=PENDING`).

## 3. Insight Schema Contract

```typescript
export interface BusinessInsightDto {
  id: string;
  title: string;
  category: "opportunity" | "warning" | "performance" | "recommendation";
  summary: string;
  evidence: {
    metric: string;
    value: string | number;
    period: string;
    context?: string;
  };
  recommendedAction: string;
  destination: string;
  source: "ai-generated" | "rule-based";
  confidence: "high" | "medium" | "low";
  createdAt: string;
}
```

## 4. Deterministic Rule Matrix (Zero-Config Grounding)

When no external AI credentials are configured, the engine evaluates the following deterministic rule matrix:

| Domain | Trigger Condition | Category | Generated Insight & Action |
| :--- | :--- | :--- | :--- |
| **Inventory** | $\text{OutOfStock} > 0 \lor \text{LowStock} > 0$ | `warning` | Depleted figures alert with count of units and top constrained figure. Action: `/admin/inventory`. |
| **Collections** | Collection $C$ holds $> 50\%$ revenue share | `performance` | Highlights dominant anime universe (e.g. One Piece) and units sold. Action: `/admin/categories`. |
| **Cash Flow** | $\text{Pending COD} > 40\%$ of GOV | `warning` | Cash risk alert detailing uncollected cash across open shipments. Action: `/admin/orders`. |
| **Fulfillment** | $\text{Orders in PENDING} > 0$ | `recommendation` | Immediate review callout to prevent same-day courier dispatch delay. Action: `/admin/orders?status=PENDING`. |
| **Telemetry** | First-party tracking active | `opportunity` | Browsing engagement report (sessions, product views, view-to-bag rate). Action: `/admin/products`. |

## 5. External Provider Configuration

To activate Google Gemini LLM generation:
1. Provide a valid Gemini API key in `apps/api/.env`:
   ```bash
   GEMINI_API_KEY=your_gemini_api_key_here
   ```
2. The engine will automatically detect the key, format the strictly grounded prompt, enforce `responseMimeType: "application/json"`, and validate the returned JSON against the schema.
