# Homepage, About and category update

The homepage now ends after the making-of section. The six-letter HIMATU scroll story and its large closing wordmark moved to `/about`.

The About page follows the supplied reference's structure: a full-width hero, a split brand story, concise reasons to explore HIMATU, a contact/shop call to action, and the six-letter story. The copy uses only established HIMATU details; it does not repeat the reference site's authenticity, shipping or price guarantees.

Collection banners now include a separate down-arrow link to the product grid. The Action Figures banner uses the original shelf photograph supplied on 13 November 2026, stored at `apps/web/public/images/collections/action-figures-shelf.jpeg`. The image is shown whole on mobile against a soft backdrop and cropped gently on desktop. Admin-selected custom covers still take precedence over the default banner.

The Explore button no longer has a diagonal arrow; the separate down-arrow is the scroll cue. The Collections desktop menu now uses the same four-column layout as Categories, grouping family links, anime favourites, more anime and other franchises. Both menus draw their entries from the category registry, so newly added active collections appear in the menu.

New Arrivals moved from top-level navigation into the Categories mega menu, the mobile menu immediately after Categories, and a featured link on `/categories`. The desktop category menu uses four clear columns: Featured, Shop by type, Anime worlds and More to explore.

The existing product, order, checkout, account and admin routes were not changed by this update.
